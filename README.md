# Go Hello World (Build Version Example)

Простой веб-сервер на Go, демонстрирующий работу со строкой версии сборки и feature flags.

## Функциональность

Сервер поддерживает следующие функции, управляемые через command-line flags:

1. **IP Address Detection** - показывает IP адрес клиента
2. **Country Detection** - показывает страну клиента (использует ip-api.com)
3. **Name Form** - показывает форму для ввода имени и фамилии

## Command-Line Flags

Все функции можно включать/выключать через command-line флаги:

```bash
./hello-world [flags]
```

### Доступные флаги:

- `-ip` - Показывать IP адрес клиента
- `-country` - Показывать страну клиента
- `-form` - Показывать форму для ввода имени и фамилии
- `-help` - Показать справку по использованию

### Примеры использования:

```bash
# Показать только IP адрес
./hello-world -ip

# Показать IP адрес и страну
./hello-world -ip -country

# Показать только форму для ввода имени
./hello-world -form

# Показать все функции
./hello-world -ip -country -form

# Показать только базовое сообщение (без функций)
./hello-world

# Показать справку
./hello-world -help
```

## Сборка

Вы можете указать версию сборки при компиляции с помощью `-ldflags`:

```bash
go build -ldflags "-X main.buildVersion=3.0.0" -o hello-world_3.0.0
```

## Запуск

```bash
./hello-world_3.0.0 [flags]
```

http://localhost:8080

## Использование

1. **С формой (`-form`)**: При переходе на сайт появится форма для ввода имени и фамилии
2. **Без формы**: Сразу показывается информация о клиенте (в зависимости от включенных флагов)

## Примеры вывода

### С формой и всеми функциями:
```bash
./hello-world -ip -country -form
```
```
Build version: 3.0.0
Hello John Doe!
Your IP address: 192.168.1.100
Your country: Russia
```

### Только IP адрес:
```bash
./hello-world -ip
```
```
Build version: 3.0.0
Your IP address: 192.168.1.100
```

### Только базовая функциональность:
```bash
./hello-world
```
```
Build version: 3.0.0
```

## Примечания

- По умолчанию все функции отключены
- Функция определения страны требует интернет-соединения
- Локальные IP адреса (127.0.0.1, 192.168.x.x, 10.x.x.x) показывают "Local Network" вместо страны
